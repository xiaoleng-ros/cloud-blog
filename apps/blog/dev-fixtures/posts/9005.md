## 先说结论

模板感不是配色问题，是**所有东西都等分**。手写的界面会故意让某一块重一点。

## 六个动作

1. 标题不要居中，让它和正文左线对齐；
2. 图标一律本地化，别用 CDN 字体；
3. 悬停要有反馈，但反馈时长控制在 120ms 左右；
4. 描边、外沿、内容三条线分开量，"对齐"通常指最后一条；
5. 空状态要占位，不要塌陷成一条缝；
6. 同一类控件的样式一次改完，别留一个特例。

### 关于第 4 条

这是最容易返工的一条。我吃过好几次亏：改完描边以为对齐了，实际内容线还差 2px。

```css
/* 三条线：外沿 / 描边 / 内容 */
.card { border: 1px solid; padding: 14px; }
```

> 微调等于没改。要么不动，动就要看得出。
