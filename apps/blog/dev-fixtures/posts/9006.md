## 经过

改了一版后台样式，刷新看不到变化，于是回头又改了三版，越改越糟。真正的原因为：样式文件带内容哈希，但预览页读的是构建产物快照。

## 自查顺序

```bash
# 1. 计算样式到底是谁
getComputedStyle(el).padding
# 2. 请求命中的文件名带不带新哈希
# 3. 勾上 Disable cache 再刷一次
```

## 教训

- 先自证，再动手；
- 报错指向哪一层，就在哪一层验证；
- 生成物不要手改。
